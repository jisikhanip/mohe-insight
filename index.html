YoutubeUploader

개인용 도구 · Personal tool

내 유튜브 채널 성과를 읽기 전용으로 모으는 개인용 도구입니다. 채널 운영자 본인이 자기 PC에서만 사용하며, 일반 사용자에게 제공하는 서비스가 아닙니다.

  • Google OAuth로 운영자 본인 채널에 대한 읽기 전용 권한(YouTube Data API youtube.readonly, YouTube Analytics API yt-analytics.readonly)만 요청합니다.
  • 조회수·좋아요·댓글 수·시청 지속률 같은 채널 통계를 읽어 운영자의 PC에 표와 요약으로 저장합니다.
  • 영상 업로드·수정·삭제·댓글 작성 등 쓰기 작업은 하지 않습니다.

This is a personal, read-only tool that collects performance statistics of the owner's own YouTube channels and stores them only on the owner's PC.
