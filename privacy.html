개인정보처리방침 (Privacy Policy)

시행일: 2026-11-15 (2026-11-16 댓글·30일 보관 항목 추가) · 앱: Mohe Insight (모헤 인사이트) — 개인용 읽기 전용 채널 성과 도구

1. YouTube API 서비스 사용

이 앱은 YouTube API 서비스(YouTube API Services)를 사용합니다. 이 앱을 쓰는 것은 YouTube 서비스 약관에 동의하는 것이며, Google이 데이터를 다루는 방식은 Google 개인정보처리방침을 따릅니다.

2. 읽는 데이터 (읽기 전용)

  • youtube.readonly — 운영자 본인 채널의 채널 정보, 공개 영상 목록, 영상별 조회수·좋아요 수·댓글 수
  • yt-analytics.readonly — 운영자 본인 채널의 시청 지속률, 평균 시청 비율, 유입 경로, 구독 증감 같은 분석 통계
  • 운영자 본인 채널 영상에 달린 공개 댓글(댓글 내용, 작성 시각, 좋아요 수, 답글 여부, 작성자 표시 이름) — 운영자가 직접 답글을 쓰기 위해 읽기만 합니다. 댓글은 최대 30일 보관 후 자동 삭제하며, 작성자 표시 이름은 화면 표시용으로만 쓰고 따로 모으지 않습니다.
  • 다른 공개 채널의 공개 영상 정보(제목, 길이, 올린 시각, 조회수) — 참고용 목록으로만 보여 주며 최대 30일 보관 후 자동 삭제합니다.

쓰기 권한(업로드·수정·삭제·댓글 작성)은 요청하지 않으며, 댓글 답글 게시와 영상 업로드는 운영자가 YouTube에서 직접 합니다. 시청자 개인을 식별하는 정보는 수집하지 않습니다.

3. 저장 위치

읽어 온 통계와 접근 토큰은 운영자 본인의 PC에만 파일로 저장됩니다. 별도 서버나 클라우드로 보내지 않습니다.

4. 제3자 공유

수집한 데이터를 제3자에게 제공·판매·공유하지 않습니다. 광고나 사용자 추적에 쓰지 않습니다.

이 앱이 Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
